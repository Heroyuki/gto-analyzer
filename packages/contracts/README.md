# packages/contracts

API／ジョブの共通型と、学習画面のv1 JSON契約・実行時検証を配置する。アプリ／AWS SDKに依存しない。

`@gto-analyzer/contracts/spot`はカード、局面、戦略、数値精度、JSON検証を公開する。`spot/sample`は説明用のデータ。bbは0.1〜100000（スタックは0可）、小数3桁。ベット率は0〜100000000、小数2桁。頻度は0〜100、小数2桁で合計100。UTF-8 1 MiB以内。未知version・重複カード・不正頻度・過剰桁を拒否する。

solver出典は自己申告であり、アプリによる検証済みGTOではない。今後のレビュー契約は別途追加する。
