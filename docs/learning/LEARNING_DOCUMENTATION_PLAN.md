## 棚卸し方法

ロードマップの全対象ページについて、ページID、題名、テーマ、Cash/MTT、依存する知識、本文の有無、不足項目、出典、編集状態を台帳に記録する。「学習済み」と「ドキュメント完成」は別の状態にする。

対象一覧を作った後、MTTレビューに必要な以下のテーマから優先する。Cash/PLO等の既存資料は削除しない。全体の完成対象に含める範囲は棚卸し時に確定する。

1. ポジション、スタック、アンティ、ポット、SPR、ポットオッズ。
2. MTTのプリフロップ、ショートスタック、各ストリートのレンジ推論。
3. chipEVと賞金EV、ICMの前提と必要データ、バブルとFT。
4. マルチウェイ、サイドポット、バウンティ等の適用限界。
5. レビューの読み方、計算値・推定・ソルバー結果の違い。

## ページごとの完成条件

- 定義と用語の意味が明確で、関連用語集に接続している。
- 適用するゲーム形式、人数、スタック、その他の前提を明記している。
- 具体例と実戦判断への応用があり、数値例の計算を検算している。
- 成立しない場面や必要情報が不足する場面を説明している。
- 根拠となる一次資料のリンクと確認日を記録する。
- 他ページと矛盾する場合は解消するか、適用条件の差を説明する。
- 未確認の主張や未解決事項が残るページは完成扱いにしない。

## アプリとの接続

ページIDとテーマタグを安定した参照として使い、レビューには参照した資料の版・更新日時を残す。初期版は担当者が関連付けを確認したテーマ別マッピングを使う。自動でNotion全体を検索する機能は初期版に含めない。

個人のNotion資料はそのまま他ユーザーへ配信しない。共通知識として利用する本文・リンクは共有可能性を確認したものに限定する。私有ページを参照できないアカウントにはリンクや本文を表示せず、資料連携なしでもレビューを利用できるようにする。

共有可能性の確認は、資料所有者による明示的な共有承認、公開カタログの許可リスト登録、承認された版の固定を指す。未承認本文は他ユーザーのレビュー用LLM入力や共有キャッシュにも入れない。初期版は私有本文を同期せず、共通資料には承認済みスナップショットだけを使う。私有リンクはアプリ上の所有者に限定し、Notion側のアクセス権を自動判定できる前提は置かない。

## レビューと受入

理論レビューでは数値の検算、前提条件、出典の裏付け、MTTへの適用を確認する。アプリ連携レビューではレビュー結果のテーマと参照資料が合致すること、および資料のアクセス境界を確認する。

完了報告には対象ページ一覧、完成件数、保留件数と理由、修正した矛盾、アプリから参照できる資料一覧を添付する。現時点では全ページの監査・編集は未実施。
